# سكربتات فيديو أحمد (نسخة الموبايل)

مكتوبة وشغالة على **لينكس**. على ويندوز هتحتاج تعديل في المسارات (`/tmp/...` و`../voice12/clean/...`) والأوامر. ماجرّبتهاش على ويندوز.

## الملفات
- `texts.py`: نص التعليق الصوتي لكل مشهد (01..12).
- `dur.json`, `sched.json`, `off.json`: أزمنة المشاهد (من مدة كل ملف صوت).
- `rec.py`: تسجيل شاشة الموقع بـ Playwright (موبايل)، مع API وهمي. لازم يضغط زر اللغة "عربي" أولاً.
- `panel.py`, `intro_m.py`, `outro.py`: رسم اللوحة والمقدمة والختام بـ PIL إلى فيديو.
- `subs.py` + `subs.json`: الترجمة (يتم رسمها كصور PNG شفافة بخط Cairo).
- `final.py` + `final_plan.json`: الشارات والتأثيرات.
- `audio2.py` + `audio_plan.json`: دمج الصوت والموسيقى والمؤثرات (`fx/`).
- `poses/`, `chips/`, `lg/`, `badges/`: صور أحمد والشارات.

## مش موجود هنا (لازم تعمله)
- ملفات الصوت (`voice12/clean/01..12.wav`): كانت من Speko (voice carina, ar-EG, speed 1.2) ثم: `rubberband=pitch=1.22:formant=shifted,equalizer=f=3500:t=q:w=1:g=3,acompressor=threshold=-20dB:ratio=3:attack=5:release=80,loudnorm=I=-16`، تردد 44100.
- الموسيقى الخلفية (`music_long.wav`): هادية جدًا، بمستوى حوالي 45%.
- أمر التجميع النهائي ما اتحفظش كسكربت: القطع (مقدمة + شاشة فوق لوحة + ختام) تتجمع بـ ffmpeg مع الشارات من `final_plan.json` والصوت، ثم ترميز libx264 crf 20.
